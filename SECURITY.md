# Security

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/tukorama/mcp-server-polymarket/security/advisories/new),
not in a public issue. Issues that could let an agent place an order, move funds or reach a
recipient without the user's confirmation are the most important to hear about.

Never paste a private key, API secret or passphrase, `session.json`, `perps_session.json` or the
write journal into an issue.
